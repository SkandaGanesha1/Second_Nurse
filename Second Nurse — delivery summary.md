# Second Nurse — delivery summary

## Built

Second Nurse is a working synthetic agent-safety control room with six functional views: Ward overview, Agent workspace, Action pack, Audit ledger, Research library, and Runtime connection. The Python backend includes four fictional patients, nine official MCP tools, an actual deterministic raw-before transcript, a nonexecuting illustrative-reference lane, a fail-closed official AgntID SDK adapter, and independently inspectable local evidence.

The differentiated idea is an **evidence workbench for task-specific regulated action packs**: useful drafts survive narrow authority, and actual tool execution is distinguished from the model's narrative. This is a practical novelty hypothesis, not a world-first claim. The user-provided Second Nurse specification has been preserved rather than replaced with a generic security dashboard.
