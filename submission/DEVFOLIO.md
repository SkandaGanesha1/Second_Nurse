## Tagline

Useful clinical-agent drafts. Independent authority at the tool boundary.

## Problem

An agent that reads private context and untrusted chart text while holding irreversible tools can turn content into unauthorized action. A system-prompt reminder is not a hard authorization boundary, and a model's final prose cannot prove whether the action happened.

## What we built

A synthetic four-patient ward with nine small MCP tools; a projector-ready control room with three explicitly separated modes; before/after task scenarios; argument/result inspection; a hash-linked local evidence ledger; a versioned intended action pack; and a cited research library. The useful task is to prepare unsigned transfusion/heparin drafts. Synthetic numeric bounds and high-impact tool classes are intended to be enforced by genuine AgntID, not a replacement local engine.

## AgntID role

The protected adapter uses the official Python SDK to discover actual names, open a task with trusted identity and prompt, require accepted prepared intent, maintain its shortlist, call the wrapped client, handle real denial, and close the task. Missing runtime or SDK fails closed with no raw fallback. The intended portal configuration is Medium/READ_WRITE; units 800–1200, IV route_code 1–1, volume_ml 200–350; execute sign/message and delete discard excluded.
